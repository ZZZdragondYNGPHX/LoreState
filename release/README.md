这是一套 Discord 试用发布材料，尚未代你发送帖子或上传附件。

建议发布顺序：复制 `Discord帖子.md` 作为主帖，附上 `状态栏模板.html`、`状态栏条目.txt` 和 `作者改造教程.md`。脚本使用主帖里的 `prototype-v0.9.2` 固定版本链接；主帖另列 `main` 分支持续更新入口，不需要读者下载整个仓库。

| 文件 | 用途 |
| --- | --- |
| `Discord帖子.md` | 可复制的标题和正文 |
| `状态栏模板.html` | 可粘贴到 LoreState 的三栏目样式；打开文件只显示示意内容 |
| `状态栏条目.txt` | 可粘贴到角色绑定世界书的状态描述规则，不是可直接导入的世界书 JSON |
| `作者改造教程.md` | 配置、旧模板改造、预设与故障处理 |
