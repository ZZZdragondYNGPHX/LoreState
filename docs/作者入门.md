# 作者入门 · 当前固定版 0.12.3

LoreState 用来记录“这一轮之后仍然成立”的事实：当前地点、人物伤势与目标、物品持有者、国家政局、未完成事件等。正文仍由原来的叙事模型生成；LoreState 只额外维护一份可回放、可增量更新的文字状态。

当前稳定版是不可移动标签 **`0.12.3`**。正常使用优先固定版；`main` 是持续开发入口。需要 SillyTavern 与酒馆助手（Tavern Helper）。

## 你需要准备三样东西

| 材料 | 负责什么 |
| --- | --- |
| 角色设定和世界观 | 人物、世界、叙事风格与剧情规则 |
| LoreState 模块条目 | 定义保存哪些公共栏目/模块栏目，以及什么时候更新 |
| Template API v2 HTML | 只决定这些状态怎么显示，不决定 DataSchema |

**当前 DataSchema 由模块条目定义，不再由 HTML 绑定反推。** HTML 可以只显示部分字段、重复字段或完全不显示某个模块；这不会删除状态里的对应数据。

## 第一次试做

1. 导入 [0.12.3 固定远程组件](../prototype/dist/0.12.3/lorestate-script.json)，只启用一份 LoreState。只有明确要跟随开发时才使用 [main 组件](../prototype/dist/main/lorestate-script.json)。
2. 在角色或聊天绑定的世界书中新建状态栏条目。最简单可以直接复制 [模块条目示例](../prototype/module-example.txt)。
3. 打开 **魔法棒 → LoreState 设置**，选择这本世界书与刚创建的状态栏条目。
4. 点击 **确认绑定状态栏条目**。0.12.1 会保存这一步的选择，刷新列表或切到外观制作再回来不会默认跳到第一条。
5. 打开 **外观制作**。可以复用 API 预设生成/修改 HTML 草稿，也可以直接粘贴 [紧凑日志](../prototype/module-example.html) 或 [旅途档案 HUD](../prototype/example.html)。当前模板必须使用 Template API v2。
6. 预览外观；确认无误后应用草稿/预设，并在设置中点击 **保存 HTML 并启用本聊天**。
7. 发一条普通玩家消息。第一次有效状态回复建立完整状态，之后只输出发生变化的栏目。用“查看下一轮状态提示”和诊断页核对实际规则、当前状态与错误信息。

确认绑定只保存准备使用的世界书与条目，不会提前写状态或改变世界书活动规则。先配置再开始试卡，比在已有几十轮正文的聊天中途首次启用更容易判断问题来源。

## 模块条目怎么理解

当前推荐格式：

```text
【LoreState模块 v1】
【通用规则】
只记录正文已经确认的持久事实。

【公共栏目】
栏目：地点、时间
明确移动或时间推进时更新。

【模块：人物】
栏目：身体状况、当前目标
受伤或恢复时更新身体状况；明确改变意图时更新当前目标。

【模块：物品】
栏目：持有者、完好状况
交付、遗失、损坏或修复时更新。
```

公共栏目属于整个场景；不同实体模块可以拥有不同栏目。更完整的写法、冷热档、事件与关联规则见 [状态栏条目创作指南](状态栏条目创作指南.md) 和 [0.9.0 模块设计说明](0.9.0模块条目与试卡.md)。

## HTML 怎么理解

Template API v2 文档根需要：

```html
<html lang="zh-CN" data-lore-template="2">
```

公共值使用 `data-lore-shared`；实体先用 `data-lore-each="模块名"` 建立区域，再在区域内使用 `data-lore-field`。准确语法与安全边界见 [HTML 模板适配指南](HTML模板适配指南.md)。

外观只接受受限静态 HTML/CSS，不执行自定义 JavaScript、远程图片/字体或任意网络资源。外观制作台生成的内容也必须先经过同一套校验，模型不能直接修改当前外观。

## 需要自己写 XML 吗

通常不需要。脚本每轮会把当前 schema、状态、读取权限和输出协议交给模型。作者主要负责写领域规则；XML 用来排查“首次完整、以后增量”是否正常。

不要再要求模型每轮重写整张 HTML，也不要另造一套 `<状态栏>` 协议。一个栏目发生变化时输出该栏目的**完整新值**；没有变化的栏目由 LoreState 继承。

## 可选能力

- [额外模型与 API 预设](额外模型与API预设.md)：把状态更新交给独立模型，支持重试、取消、手动重算与撤销。
- [外观制作台](外观制作台.md)：用已保存 API 从风格描述生成/修改 v2 HTML 草稿。
- [EJS / 动态世界书](EJS动态世界书.md)：可选接入 ST-Prompt-Template，只读读取 LoreState 冻结快照，根据区间/阶段输出当前适用的世界书内容。
- [隐藏助手兼容与更新](隐藏助手兼容与更新.md)：隐藏历史正文时保持本地状态回放连续。
