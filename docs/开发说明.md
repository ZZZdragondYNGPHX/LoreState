# 开发入口与目录约定 · 当前 0.12.3

当前唯一活动维护线是 `prototype/` 的 Tavern Helper 脚本；`main` 是唯一长期开发分支。固定稳定版为不可移动标签 **`0.12.3`**。根目录旧原生扩展不是当前维护线。

版本/分支强制规则以 [版本管理](版本管理.md) 与根目录 [AGENTS.md](../AGENTS.md) 为准。

## 构建与测试

要求 Node.js 22+。

```sh
npm run build
npm run check
npm test
```

涉及模板、控制中心或宿主事件时：

```sh
node scripts/test-browser.mjs
```

涉及 EJS 时按任务再运行：

```sh
node scripts/test-ejs.mjs
```

这些是自动化/模拟宿主验证，不等于真实 SillyTavern、真实模型或手机验收。

## main 构建

`npm run build` 只更新：

- `artifact/bundle.js`
- `prototype/dist/main/lorestate-script.json`
- `prototype/dist/main/receipt.json`

main loader 必须只引用 `@main/artifact/bundle.js`。

## 新固定版本

当前 `0.12.3` 已发布。下一 patch 示例：

```sh
npm run build -- 0.12.4
npm run check
npm test
node scripts/test-browser.mjs
```

这会生成 `prototype/dist/0.12.4/`。固定 loader/receipt 必须固定到 `@0.12.4`；提交维护源和生成物并完成检查后，再创建同名不可移动 tag。

语义版本号只属于 tag，不属于 branch。已发布 tag 永远不移动。

## 0.12.3 配置重置

“彻底删除旧配置”是结构化重建能力，不是简单 UI 清空：

- 删除本脚本栏目/世界书绑定/HTML/命名外观预设/作者默认配置；
- 删除当前聊天 LoreState 状态、快照、回档、更新绑定、恢复备份；
- 保留聊天正文、世界书、全局 API 预设、其他命名空间和显示过滤；
- 其他旧聊天不批量删除，但通过配置代次隔离，重新启用时再清理旧状态。

维护时必须保留 generation/chat/config 变化保护，避免删除进行中请求或让迟到结果写回新配置。详见 [0.12.3 发布说明](发布材料/0.12.3-配置重置与多协议API.md)。

## 0.12.3 模型连接

四种连接路径：酒馆助手 OpenAI 兼容、Chat Completions、OpenAI Responses、Anthropic Messages。原生协议支持普通 JSON 与 SSE、完整端点/查询参数、自定义请求头，并可通过 `preset-bridge.js` 复用当前/指定酒馆提示词预设。

原生协议走浏览器网络环境，因此 CORS、HTTPS→HTTP 限制和第三方网关特殊鉴权必须在真实环境验收。Gemini 原生协议、Bedrock 签名鉴权不属于当前范围。

## Template API v2 与 EJS

Template API v2 只消费模块 DataSchema，不定义状态字段；预览、命名预设、聊天渲染和展开窗口应走同一校验链。

EJS 桥接不导入 EJS 引擎，只通过 Prompt Template prepare 时机暴露深冻结只读快照/helper。不可追踪生成、历史缺口、聊天切换和重入宁可返回空态。

## 固定版本问题怎么查

用户报告固定版本问题时，先确认实际加载 ref，再读取该 tag 的维护源和 bundle；需要临时日志时从精确 commit 建 `debug/<version>-<slug>`。修复最终进入维护源、补回归、重新 build/check/test，稳定交付发布新 patch，不移动旧 tag。
