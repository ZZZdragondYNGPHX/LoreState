# 开发入口与目录约定

当前开发线是 `prototype/` 的酒馆助手文字状态脚本。目录名暂时保留，避免整理和协议迁移混在一起。根目录原生扩展仍供旧用户安装，保留其 manifest 和入口路径。

| 路径 | 维护职责 |
| --- | --- |
| `prototype/core.js` | 标签解析、合并、回放、提示词 |
| `prototype/template.js` | HTML 校验与文字绑定 |
| `prototype/presets.js` | 随卡预设 |
| `prototype/runtime.js` | 宿主接入、界面与事件 |
| `prototype/example.html` | 默认样式 |
| `scripts/build-prototype.mjs` | 打包入口，发布版本与 CDN 地址 |
| `artifact/bundle.js`、`prototype/dist/` | 构建产物，不能只改这里 |
| `tests/` | 新脚本与旧扩展回归 |
| `src/`、根目录入口和 manifest | 旧原生扩展兼容线 |
| `examples/` | 旧扩展示例与迁移材料 |

仓库根目录运行 `npm test`、`npm run check`、`npm run build`。不需要 npm install。构建不会发布、安装或调用模型；无源码及版本变化时产物应保持一致。

发布时更新构建脚本版本、生成产物并校验，Git 标签须与 import 版本一致。不覆盖已发布标签。当前构建目标为 `prototype-v0.5.0` 本地候选版，写入 `prototype/dist/v0.5.0/` 与 `artifact/bundle.js`；尚未发布。旧 `prototype/dist/` 根目录和缄愿笔记构建仍固定 0.4.0，不代表已升级。

真实宿主检查与反馈见 `prototype/verification.md`；自动测试不代替实机验收。旧交接原件见 `docs/交接文档_旧扩展0.2.1.md`。
