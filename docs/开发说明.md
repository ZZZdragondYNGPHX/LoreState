# 开发入口与目录约定

当前维护线为 `prototype/` 的酒馆助手脚本，功能基线 0.9.0；main 包含隐藏兼容修复。根目录原生扩展保留为旧实现。作者从[文档目录](README.md)进入。

| 路径 | 职责 |
| --- | --- |
| `prototype/core.js` | 标签解析、合并、状态回放与提示词 |
| `prototype/modules.js` | 模块栏目与按需规则 |
| `prototype/runtime.js` | 宿主接入、管理器与事件 |
| `prototype/snapshots.js`、`snapshot-store.js` | 快照、回档、历史身份和读取凭据存储 |
| `prototype/template.js`、`state-frame.js` | 模板校验、安全绑定与状态窗口 |
| `scripts/build-prototype.mjs` | 脚本构建与版本化分发配置 |
| `artifact/bundle.js` | main 的完整脚本代码 |
| `prototype/dist/` | 各版本组件与收据 |
| `tests/` | 脚本和旧扩展的自动回归 |
| `src/`、`index.js`、`manifest.json` | 旧原生扩展 |

## 检查与构建

Node.js 22+，核心检查无需安装第三方依赖。

```sh
npm test
npm run check
node scripts/test-browser.mjs
```

浏览器检查默认使用 Windows Edge；可通过 `LORESTATE_BROWSER` 指定浏览器可执行文件。它测试模板和最终 `artifact/bundle.js` 的模拟宿主行为，不是实际酒馆验收。

`npm run build` 运行 `scripts/build-prototype.mjs`。该脚本目前仍固定输出 `prototype/dist/v0.9.0/` 和 `artifact/bundle.js`，远程入口固定 `prototype-v0.9.0`，收据含历史发布标记。直接运行会用当前源码改写旧版本目录；生成物不能因此被称为已发布的新版本。准备新分发时须先选择新版本、输出目录与远程 ref，再构建和校验；不得覆盖已发布标签。本次 main 修复未重发旧组件。

## 隐藏楼层回归约定

本地状态历史包含隐藏的 AI 消息；隐藏只是上下文可见性。回放、诊断和快照应保持一致。历史身份忽略隐藏位，但保留楼层、角色、回复分支和原文；旧回档前缀的隐藏位可归一化比较。真正的原文变动仍受校验。

相关回归在 `tests/hidden-history.test.mjs` 与 `tests/runtime-browser.js`。不得把私人聊天作为仓库测试夹具；使用合成数据覆盖同类条件。
