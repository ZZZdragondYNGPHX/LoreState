# 状态栏条目创作指南 · 当前模块格式

当前作者条目使用 **`【LoreState模块 v1】`**。人物、物品、国家、组织、地点、事件等模块可以有各自不同的栏目；HTML 只负责展示，不负责定义 DataSchema。

一条好的规则要回答四件事：**记什么、什么时候更新、没有证据时怎么办、哪些对象需要持续加载。**

## 最小结构

```text
【LoreState模块 v1】
【通用规则】
只记录正文已经确认的持久事实；猜测、计划和未发生事件不写成当前事实。
新档案缺少明确资料时写“未知”。跨模块变化同轮保持一致。

【公共栏目】
栏目：地点、时间
明确移动或剧情时间推进时更新。

【模块：人物】
栏目：身体状况、当前目标
身体状况只在受伤、恢复或持续异常明确变化时更新。
当前目标只在人物真实改变意图或旧目标失效时更新。

【模块：物品】
栏目：持有者、完好状况
交付、遗失、损坏或修复时更新。
```

第一行必须是格式标记。每个公共/模块分区的首个非空行用 `栏目：`；多个栏目用中文顿号 `、` 分隔。

当前解析边界：模块至少 1 个、最多 16 个且不能重名；公共栏目最多 32 个；所有实体模块合计最多 32 个不同栏目名。模块/栏目名最长 40 字符，使用文字或下划线开头，后续可含文字、数字、下划线、连字符。条目及本轮组装内容受 24000 字符预算约束。

## 公共栏目与实体模块

公共栏目适合整个场景共享的事实，例如地点、时间、全局任务阶段。不要把所有人物关系和历史都塞进一个巨大的公共栏目，否则实体转冷也无法降低这部分提示占用。

模块用于分类实体，常见示例：

| 模块 | 栏目示例 |
| --- | --- |
| 人物 | 身体状况、当前目标、关系描述、身份状态 |
| 物品 | 持有者、完好状况、用途、当前位置 |
| 国家 | 政局、外交、战争状态 |
| 组织 | 领导者、立场、当前行动 |
| 地点 | 控制者、危险、当前状态 |
| 事件 | 事项、进展、触发条件、截止时间 |

## 更新规则写到栏目级

不要只写“记录当前状态”，要说明什么时候才改：

```text
【模块：人物】
栏目：身体状况、当前目标
身体状况：只记录正文明确发生的伤势、疲劳、恢复和持续异常；没有证据时不自行痊愈。
当前目标：只有人物明确改变当前意图或剧情已使旧目标失效时更新；普通交谈不自动改变目标。
```

一个栏目内部是**完整当前值替换**。状态是当前事实，不是变化日志。

## 未知与证据边界

推荐在通用规则明确：

```text
只记录正文已经确认的结果。
猜测、计划、传闻与未发生事件不视为既成事实。
新档案缺少的信息写“未知”，不凭空补重大事实。
人物自述尚未得到确认时，可标注“自称/未证实”。
```

## 跨模块变化

人物把钥匙交给守卫时，如果 schema 同时记录人物持有物、物品持有者和交付事件，就应在同一 LoreState 更新中保持一致。不存在的栏目不要为了“同步”而临时发明。

## 热档、冷档、links 与事件

暂时无关的实体可以转冷，完整档案仍保存在本地。冷档被准确提及、被活动对象通过 `links` 带出或满足其他读取条件时可重新提供给模型。

**读取冷档不等于自动获得写权限。** 冷档写入仍受当轮读取凭据与状态校验保护。

`links` 是有向的一跳读取，不自动反向，也不无限递归。只关联当前真正需要一起读取的对象。

未完成且会持续影响剧情的承诺、追杀、交付、战争影响、倒计时等，适合独立做“事件”。时间到达不代表事件自动完成；只有正文明确完成/取消后，才应更新为结束状态并按规则转冷。

## 数值字段与 EJS

状态值仍以文字保存。可以把好感度写成 `-63`，但 LoreState 本身不自动加减、不做战斗结算。

如果需要“数值区间决定本轮世界书内容”，使用 0.12.0 起提供、当前 0.12.3 继续兼容的 [EJS 只读桥接](EJS动态世界书.md)。

## HTML 不定义栏目

Template API v2 中：

- 公共值：`data-lore-shared`；
- 实体区域：`data-lore-each="模块名"`；
- 模块字段：each 内的 `data-lore-field`；
- 可只展示部分字段、重复字段、同类多区域和 cold 区域。

隐藏字段只是换皮肤，不会从状态里删除字段。详见 [HTML 模板适配指南](HTML模板适配指南.md)。

## 修改已有条目

只修改自然语言规则、栏目集合不变时，可以继续使用现有 DataSchema。

**增删/改名模块或栏目属于结构变化。** 0.12.3 不再要求靠另建脚本绕过去，而是提供明确的重置流程：在 **规则配置 → 聊天维护** 输入 `删除旧配置`，执行 **彻底删除旧配置**，然后重新绑定条目、制作/应用匹配新 schema 的 HTML、再启用聊天。

重置会清除本脚本配置和当前聊天的 LoreState 状态/快照/绑定，但保留聊天正文、世界书和全局 API 预设；不可撤销，重要数据先备份。详情见 [作者入门](作者入门.md) 与 [0.12.3 发布说明](发布材料/0.12.3-配置重置与多协议API.md)。
