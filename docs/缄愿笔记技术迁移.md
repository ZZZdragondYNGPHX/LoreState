## 验收场景

1. 新聊天首次完整记录，以后只更新变化，未提及愿效保留。
2. 即时愿成为事实；仅持续约束及未来目标保留独立条件。
3. 两个相近人物编号不混淆；离场保留，重返取回，不重复新增。
4. 编辑、重抽、删除楼层后，状态跟随当前历史。
5. 显示隐藏协议；模型保留正文，仅注入所需当前状态。
6. 刷新、换聊天、导出再导入不串档；旧世界书原件可回退。

待用户确定：先保留旧冷档、迁移热档显示与增量，或本次补齐新冷档并替换整套维护 QR。该选择会改变协议与依赖，不默认简化成全量发送所有人物。
