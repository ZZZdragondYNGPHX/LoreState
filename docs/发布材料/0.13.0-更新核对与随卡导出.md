# LoreState 0.13.0 · 更新前核对与随卡导出

## 改动

- 同一次状态请求先逐项输出短核对摘要，再输出更新块；校验栏目覆盖、实际变化、读取权限和摘要一致性。额外模型缺摘要会重试；旧记录保持可回放。
- 自定义核对规则随角色卡保存，适配不同状态栏；支持默认恢复、两种更新模式、重算与提示预览。
- 规则条目保留随卡副本，接收方缺少原世界书时可使用；新增可移植更新默认值。
- 新增导出准备入口，同步规则、检查作者初值/字段约束和外观，并开启自己的脚本数据/按钮导出开关。其他脚本、个人 API 和聊天进度保持原作用域。
- 作者默认档案原本已随卡保存，本版补入导入恢复验证。核对后的截断状态块仍可预览边界并重算。

## 安装与升级

[0.13.0 固定远程组件](../../prototype/dist/0.13.0/lorestate-script.json)。只启用一份 LoreState；固定 loader 指向 `@0.13.0/artifact/bundle.js`，开发 loader 仍指向 `@main/artifact/bundle.js`。

从 0.12.3 升级无需重建 v3 状态、快照或合法 v2 外观。分享前保存状态更新绑定、作者默认档案，再点击“规则配置 → 角色卡导出 → 检查并准备角色卡导出”。接收方的个人连接仍需自行配置。

## 验证与边界

基底：`main / b534d3efa9b04455d0156a37e725f919e17543a7`。构建、Node、最终 bundle 模拟宿主和 EJS 的最终结果见 [验证记录](../../prototype/verification.md)。

真实模型遵循率、实际酒馆角色卡导出导入、手机及长聊天仍需实机验收；`realHostVerified=false`。本版增加结构性核对，不能保证模型对每个剧情事实都判断正确。核对摘要增加输出 tokens。
