# LoreState 0.13.1 · 更新核对路径修复

发布日期：2026-09-16。

## 修复内容

- 状态模型的**字段更新判断规则**只允许来自状态栏条目与角色卡的自定义更新核对规则。剧情正文和旧状态仅作为事实资料；内置提示只保留协议、权限与格式约束。
- 删除 `LoreStateReview` 中硬编码的 `/shared/地点` 示例以及“重点检查时间/地点/关系/事件”等默认语义提示。
- 根据当前 DataSchema 和本轮完整加载实体动态生成精确核对 path。作者字段为 `当前时间` / `当前地点` 时，模型会直接看到 `/shared/当前时间` / `/shared/当前地点`。
- 冷档未完整读取时只暴露 `/presence`，不会把不可读取字段列给模型；完整取回后才列对应字段 path。
- 纠错重试明确要求逐字复制本轮合法 path，禁止缩写、改名、翻译和同义改写。

## 兼容性

不修改 XML v3、`【LoreState模块 v1】`、Template API v2、现有状态对象、快照或角色卡随卡配置结构。`0.13.0` 可直接升级到 `0.13.1`，无需重建聊天或 DataSchema。

## 自动验证

发布流程运行：`npm run build`、`npm run build -- 0.13.1`、`npm run check`、`npm test`、`node scripts/test-browser.mjs`。新增回归覆盖真实公共栏目名 `当前时间` / `当前地点`、非法缩写 `/shared/时间`、完整加载实体精确字段 path 与未读取冷档权限边界。
