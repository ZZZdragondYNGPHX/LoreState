# LoreState 0.12.0 · EJS 动态世界书

发布日期：2026-09-13。维护基底：`main / b138ffa2c454a942c48d490217f227c002c4aa80`（原 0.11.1 发布提交）。本次由用户明确授权推送远端 main，并创建不可移动标签 0.12.0；不是 GitHub Release 页面发布，也不是人工验收通过。

## 本版内容

- 可选接入 ST-Prompt-Template 的 `prompt_template_prepare`，提供 `lorestate`、`ls`、`lsHas`、`lsRange`、`lsStage` 及 `LoreState.*`。
- 在一次 EJS context 中读取同一份深拷贝、深冻结快照；不内置 EJS、不另建变量系统、不同步 stat_data，也不提供状态写入接口。
- 使用原生 `shared` / `entities.<ID>.fields` 路径，保留文本字段；区间和阶段支持纯数字文本，不按角色名字重建映射。
- 区分普通生成、swipe/重生成/续写前态与旧楼层渲染；宿主删除重生成目标后不重复排除前一层。
- 聊天切换、历史缺口、失效回档、未完成续写等情况返回空态与原因；不把缓存中的旧好状态冒充当前事实。冲突名称不覆盖，关闭/替换 runtime 会清理监听。

需要动态世界书时，由用户自行启用 ST-Prompt-Template 及其“处理生成内容”，把 EJS 放入每轮参与生成的世界书条目。未安装此扩展时 LoreState 的其他功能不受影响，但不会执行 EJS。

## 依赖与安全边界

| 依赖/产物 | 归属与证据 |
| --- | --- |
| SillyTavern / Tavern Helper | 宿主提供；沿用项目目标 1.18.0 / 4.9.5 |
| LoreState bundle | 由本仓库 prototype 维护源构建，经原 CDN 地址远程加载 |

EJS 读取不是冷档更新凭据，不会绕过原 read receipt 与状态校验。该 Prompt Template 源码的 escaper 返回原文，因此不能把 `<%=` 当作 HTML 转义保障；不要将状态文本视为可信 HTML。
