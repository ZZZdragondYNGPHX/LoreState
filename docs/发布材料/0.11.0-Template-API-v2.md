# 0.11.0 · Template API v2 与多区域状态栏

基底：`main / f84f17fd252e90889f594ff9894b92233dbdd7a6`。正式身份是不可移动标签 `0.11.0`；其固定 loader、receipt、bundle 与维护源来自同一提交。旧标签不移动。

## 本版变化

- **分类布局**：人物、物品、事件和国家各有独立区域，默认深色「旅途档案 HUD」，另附浅色「紧凑日志」。两份模板共用同一模块条目与状态。
- **自由展示**：可只显示部分字段、重复同一字段、同类型多个区域、只显示名称或仅保留公共区。HTML 不再决定存储 schema。
- **声明式查询**：each、shared、count、empty、active/cold/all、精确 ID 与 limit；冷档布局由作者决定，不再在宿主尾部额外堆叠完整档案。
- **作者流程**：预览、保存、样式预设与重载渲染全部接入同一 v2 校验器；制作提示词会列出真实模块字段，并附可运行示例。
- **容错与隔离**：旧模板及其他展示错误只阻止当前 HUD，尾部保留修正入口；状态更新、回放、快照及诊断继续运行。维持空 sandbox、静态 HTML/CSS、纯文本绑定、CSSOM 检查与资源预算。

## 升级注意：模板是破坏性变更，存档不是

新文档必须包含 `<html data-lore-template="2">`；旧 `data-lore-person/entity/module` 不执行、不自动转换。旧 HTML、预设原文保留，可在设置复制备份；重新制作 v2 并应用后恢复状态栏。

**保持不变**：XML version=3、config.version=4、模块条目格式、DataSchema、shared/entities、full/delta、状态合并、快照/回档与冷档读取凭据。升级不清空聊天，不增加存档迁移。实际模块字段变更仍受保护；换肤只改变展示。
