# LoreState 0.12.2 · 浅色控制中心

本版将脚本管理界面改为暖白背景、浅灰分区与青绿强调色，并重新安排功能位置。角色卡自己制作的 HTML 外观保持原样。

## 功能现在在哪里

| 页面 | 内容 |
| --- | --- |
| 状态总览 | 楼层切换、完整状态、本轮变化、实体档案与原始数据 |
| 更新与恢复 | 最新回复更新/重算、取消、撤销、截断确认、历史快照、楼层报告和旧备份 |
| 规则配置 | 世界书与条目绑定、初始档案、字段约束、聊天启停 |
| 外观制作 | 风格输入、AI 草稿、源码、预览、应用与命名预设 |
| 模型连接 | API 连接库、本聊天更新方式、模型绑定与请求策略 |

旧“状态重算”和“手动更新与撤销”存在重叠：两者最终都使用同一更新路径，前者还会留下按钮已隐藏的空卡片。本版移除第二个重算入口，集中保留一套更新操作。

**更新始终针对最新 AI 回复。** 上方查看楼层只影响历史状态、楼层报告等查看操作。随正文模式仅重算失败回复，额外模型模式可重新整理最新回复。遇到符合条件的尾部截断，先核对保留正文与待替换尾部，再点击“确认边界并重算”；预览不请求模型、不改消息。

桌面使用左侧导航；窄屏切为可横向滚动的导航。正文区域独立滚动，关闭与导航保持可达。支持方向键、Home/End、可见焦点、原生复选框及页面滚动位置恢复。模型配置未保存的编辑值在切页时保留。

- [0.12.2 固定远程组件](../../prototype/dist/0.12.2/lorestate-script.json)：只加载 `@0.12.2/artifact/bundle.js`。
