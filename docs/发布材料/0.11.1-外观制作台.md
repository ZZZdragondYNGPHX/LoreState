# LoreState 0.11.1 · API 辅助外观制作

基底 main / 8e28baa070841e281fa3b3113069e6d4210227eb。用户批准功能更新，并明确授权完成后推送 main 与新固定标签 0.11.1。旧标签不移动。

## 本版内容

- 控制中心新增“外观制作”页，把模板源码、预览和命名预设集中管理，顶部区分当前生效外观、草稿与生成 API。
- 风格小窗口支持从零生成、基于当前 HTML 继续改稿、请求内容预览、有限重试、总超时和取消。
- 复用 API 页已保存的模型连接与请求策略，独立组装 HTML 任务；不混入状态更新任务或酒馆请求预设。
- 模型输出只能作为校验后的草稿；显式应用才变更外观。保存/覆盖命名预设不自动应用，草稿应用不覆盖命名预设。
- Template API v2 增加条件显隐、字段值映射 class；保留空 sandbox、固定 CSP、安全白名单，不执行模型脚本或资源请求。
- 支持在初次栏目启用前保存 API 绑定，避免“先有 HTML 才能绑定用于制作 HTML 的 API”的循环依赖。

## 升级和安装

从 0.11.0 升级无需重制现有 v2 HTML，不迁移/重置 XML v3 状态、schema 或快照。从更旧模板升级仍需制作 v2 HTML，旧文本保留。新增显示属性不适用于 0.11.0。

## 数据与权限

API 密钥只存用户全局设置，不写入角色卡、HTML、聊天或请求预览。外观请求只自动发送结构化栏目、风格与改稿 HTML，不自动发送世界书原文、聊天正文或实际状态。请勿自行把私人资料放进风格/HTML；这些显式输入会发送到所选模型。

生成不自动应用，不产生状态标签；正文和状态更新与外观请求互斥。关闭窗口、切换聊天、改变草稿/栏目/API 配置后不接收迟到结果。保存作用域仍是随卡外观；本版不提供聊天级独立皮肤。
