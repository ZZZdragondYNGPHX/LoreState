## 删除旧配置后重新制卡

打开 **规则配置 → 聊天维护**，输入 `删除旧配置`，点击 **彻底删除旧配置**。随后重新选择世界书条目、制作或粘贴 HTML，再保存并启用，便可在同一脚本中改变栏目。

- 删除本脚本的栏目、世界书绑定、HTML、命名外观预设及作者默认配置。
- 删除本聊天的状态、快照、回档、更新绑定及恢复备份。
- 保留聊天正文、世界书条目、全局 API 预设与其他命名空间。标签过滤正则保留，避免历史状态标签重新进入提示词。
- 其他旧聊天的数据不会被批量删除，但因配置代次变化而停用；再次保存启用该聊天时清除其旧状态，从下一条回复开始，避免把历史正文套进新栏目。
- 生成进行中须先停止或取消。删除不可撤销；仅需暂时停用时使用“暂停本聊天”。

## 模型连接

| 协议 | 地址及使用方式 |
| --- | --- |
| OpenAI 兼容（酒馆助手） | 原有连接路径，旧预设默认保持此方式 |
| Chat Completions 直连 | 标准消息格式；可选择 `max_tokens` 或 `max_completion_tokens` |
| OpenAI Responses 直连 | 使用 `input`、`max_output_tokens`，支持普通 JSON 与 SSE |
| Anthropic Messages 直连 | 使用 `system`、`messages`、`x-api-key`，支持普通 JSON 与 SSE |

基础地址可包含 `/v1`、`/v3` 或任意代理前缀。勾选 **API 地址是完整端点** 后保留完整路径及查询参数，不再附加接口后缀。可设置自定义请求头 JSON、同源模型列表地址，也可手填模型名称。密钥与请求头仅保存在酒馆用户的全局设置中；完整设置备份可能包含这些内容。

原生协议使用浏览器直连，服务必须允许相应的跨域请求；HTTPS 页面访问 HTTP 服务还受浏览器限制。不宣称兼容每个第三方网关。Gemini 原生协议、Bedrock 签名鉴权等不在本次范围。

## 酒馆提示词预设

状态更新的四种连接方式均可选择内置、当前酒馆或指定酒馆提示词预设。原生协议通过助手完成实际提示词组装，在发送前按唯一请求标识中止助手请求，再把组装结果转换成所选协议。不切换正文的当前预设，也不额外调用旧模型；缺少桥接能力时明确报错，不退回内置提示词。

桥接支持文字消息，保留组装后的顺序及角色/世界书文字。Anthropic 的开头系统消息放入顶层 `system`，位于用户消息之后的系统提示按原顺序转成用户文字消息。原生路径的采样、长度和思考程度以 API 连接预设为准；酒馆助手路径仍按助手既有的预设参数规则处理。外观制作仍使用独立 HTML 任务，复用连接与请求策略。

## 默认值与思考程度

- 请求总次数：**3**（包含首次请求）。
- 总超时：**0**（无限等待），也可设置 15～600 秒；手动取消、关闭或切换聊天仍可停止。
- 最大回复：**8000 tokens**。
- 思考程度：**auto**，不发送思考程度参数。
- 可选 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`、`ultra`；显式选择不自动降级。`max`、`ultra` 等是否受支持由服务和模型决定，不能把选择项等同于供应商承诺。

Chat Completions 发送 `reasoning_effort`，Responses 发送 `reasoning.effort`；Anthropic 使用 adaptive thinking 与 `output_config.effort`（`none` 关闭，`minimal` 本地拒绝）。Anthropic 显式启用思考时省略采样参数，思考与回答共用最大输出额度。旧预设已保存的数值不自动覆盖。

## 验证与边界

源码、Node、最终 bundle 的模拟浏览器与 EJS 检查分别记录于[当前验证记录](../../prototype/verification.md)。真实 SillyTavern、实际 API、第三方扩展事件交互、跨域配置、手机与长期游玩仍需验收；`realHostVerified=false`。

桥接源码依据：本机 Tavern Helper **4.9.5 / af21bee2aadef5bf384f618e3456ff15ba9c431d** 的 `src/function/generate/index.ts` 与 `responseGenerator.ts`：`CHAT_COMPLETION_SETTINGS_READY` 在覆盖模型后、携带 AbortSignal 的 fetch 之前触发；`stopGenerationById` 中止对应控制器。变量删除通过同版本 `updateVariablesWith` 的 script/chat 作用域完成。源码与声明核对不代表实机验证。

协议字段依据：[OpenAI 推理模型](https://developers.openai.com/api/docs/guides/reasoning)、[Responses 流事件](https://developers.openai.com/api/reference/resources/responses/streaming-events)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages/create)、[Anthropic effort](https://platform.claude.com/docs/en/build-with-claude/effort)。

资料路由：`sillytavern-api-reference`，TavernWeave 快照 `2026-08-18`，已读取 ST-A0 与 ST-D3；未采用设计素材。实际宿主依赖仍为 Tavern Helper，EJS 为可选依赖。
