# 0.10.6 · 柏宝书与 Grid 主题兼容

基底：`main / 74139f78b3e6a1636370d43e5c678e03d613f1fb`（与 `0.10.5` 同提交）。

## 修复

部分自定义主题把 `.mes` 设为 Grid，并把 `.mes_block` 设为 `display: contents`。柏宝书的长摘要预览参与自动列宽计算，会把整个楼层内容及 LoreState iframe 撑到数千像素宽，表现为状态栏空白或内容跑出屏幕。PR4 处理的是节点脱离后的恢复，不能处理这个布局问题。

维护源 `prototype/runtime.js` 增加运行时样式，仅约束包含 LoreState 状态栏的楼层中的 `.bbs-fp-host`：`min-width: 0; grid-column: 1 / -1`。规则随 runtime 销毁，楼层重建时自动匹配；不保存或改写用户主题，不修改摘要和消息数据。

- 将维护源构建的完整 bundle 在原 Tavern Helper 脚本上下文临时执行；浏览器实取 SHA-256 与生成物一致：`ddab7eb115baae9879ed1830a750ce764eb822d53f71be6fd2f25a53021cc00c`。

边界：未调用真实模型重新生成摘要，未做手机实机或全部第三方主题验收；没有设置人工验收状态。收据的 `realHostVerified=false` 保持构建器默认，不能把此次定向布局验证扩张为产品全面验收。
