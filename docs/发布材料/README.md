# 发布材料 · 0.10.5

这是一套 Discord 试用发布材料，尚未代你发送帖子或上传附件。

建议发布顺序：复制 `Discord帖子.md` 作为主帖，附上 `状态栏模板.html`、`状态栏条目.txt` 和 `作者改造教程.md`。脚本使用主帖里的 `0.10.5` 固定远程链接；主帖另列 `main` 开发入口，不需要下载整个仓库。

| 文件 | 用途 |
| --- | --- |
| `Discord帖子.md` | 可复制的标题和正文 |
| `状态栏模板.html` | 可粘贴到 LoreState 的三栏目样式；打开文件只显示示意内容 |
| `状态栏条目.txt` | 可粘贴到角色绑定世界书的状态描述规则，不是可直接导入的世界书 JSON |
| `作者改造教程.md` | 配置、旧模板改造、预设与故障处理 |

发布前手动核对：新预设切换后数据保留；导出角色卡后在测试副本重新导入，HTML 配置、世界书关联及局部正则均可用。0.10.5 已完成自动和模拟宿主检查，真实酒馆、模型和随卡往返仍待验收，因此文案标注为原型试用。

只打包本目录及已发布远程脚本，不包含工作区的 archive、聊天测试记录或 Git 工作目录。不要改写任何旧标签；`0.10.5` 是当前完整分发的固定标签，`main` 代表持续更新的开发入口。
