# 发布材料 · 0.12.2

当前固定版为 **`0.12.2`**。本版重构浅色控制中心，合并更新入口并重新分组；保留首次条目绑定与 HTML 制作流程；同时保留 `0.12.0` 的 EJS / 动态世界书只读桥接、`0.11.1` 的外观制作台，以及 `0.11.0` 的 Template API v2。已有 v3 状态、聊天快照和合法 v2 模板继续兼容。

固定入口只引用 `@0.12.2/artifact/bundle.js`；`main` 继续作为开发入口。旧标签不可移动，不要同时启用固定版和 `main`。

首次使用的推荐顺序是：**选择世界书与状态栏条目 → 确认绑定状态栏条目 → 打开外观制作台生成/修改或粘贴 v2 HTML → 预览 → 保存 HTML 并启用本聊天**。确认绑定只保存准备使用的世界书与条目，不会提前启用聊天或修改状态。

从 `0.11.0` / `0.11.1` / `0.12.0` 升级到 `0.12.2`，现有 v3 状态、快照和 v2 外观不需要迁移。更早版本的旧 HTML 原文会保留，但需要按 Template API v2 重新制作外观。

自动化和模拟宿主检查不等于真实 SillyTavern、真实模型、手机实机或长期人工游玩验收；当前收据仍保持 `realHostVerified=false`。

本版改动与验收边界见 [0.12.2 · 浅色控制中心](0.12.2-浅色控制中心.md)。
