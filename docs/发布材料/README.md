## 当前安装/升级边界

固定入口只引用 `@0.12.3/artifact/bundle.js`；`main` 只用于开发。不要同时启用固定版与 main。

首次使用：**选择世界书/条目 → 确认绑定 → 制作或载入 v2 HTML → 预览 → 保存 HTML 并启用聊天**。

从 `0.11.0`～`0.12.2` 升级到 `0.12.3`，已有 v3 状态、快照和合法 v2 外观无需因版本升级迁移。更早旧 HTML 需要重制为 Template API v2。

主动执行“彻底删除旧配置”属于结构重建，不是普通升级，会清理当前脚本配置和当前聊天 LoreState 数据。详见 0.12.3 发布说明。

自动化/模拟宿主不等于真实 SillyTavern、真实 API、手机和长期人工验收；当前 receipt 保持 `realHostVerified=false`。
