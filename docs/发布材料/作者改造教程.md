# 给纯文字状态栏加上 LoreState · 0.12.3

适用当前固定版 **`0.12.3`**。需要 SillyTavern 与 Tavern Helper；本文只讲当前 Tavern Helper 脚本。

首次改造建议复制角色卡并使用独立测试聊天，只启用一份 LoreState。

## 1. 安装固定版

导入 [0.12.3 固定远程组件](../../prototype/dist/0.12.3/lorestate-script.json)，或使用：

```js
import 'https://testingcf.jsdelivr.net/gh/ZZZdragondYNGPHX/LoreState@0.12.3/artifact/bundle.js';
```

`main` 只用于开发，不要和固定版同时启用。

## 2. 把旧规则改成模块条目

当前 DataSchema 由**状态栏条目**定义，不再由 HTML 反推。可以直接复制 [当前模块条目附件](状态栏条目.txt) 或 [项目示例](../../prototype/module-example.txt)。

```text
【LoreState模块 v1】
【通用规则】
只记录正文已经确认的持久事实；猜测、计划和未发生事件不写成当前事实。

【公共栏目】
栏目：地点、时间
明确移动或剧情时间推进时更新。

【模块：人物】
栏目：身体状况、当前目标
受伤或恢复时更新身体状况；明确改变意图时更新当前目标。
```

删除旧世界书里“每轮重抄整张状态表”“输出另一套 `<状态栏>` 协议”“让 HTML/正则负责保存状态”等要求。输出协议由 LoreState 当轮注入。

## 3. 明确绑定条目

1. 打开 **魔法棒 → LoreState → 规则配置**。
2. 选择世界书和状态栏条目。
3. 点击 **确认绑定状态栏条目**。
4. 再进入 **外观制作**。

确认绑定不会启用聊天、写状态或修改世界书活动规则。

## 4. 制作 Template API v2 外观

可在 **模型连接 → 管理 API 预设** 保存模型，然后用外观制作台生成/修改 HTML 草稿；也可粘贴 [当前模板附件](状态栏模板.html)、[旅途档案 HUD](../../prototype/example.html) 或 [紧凑日志](../../prototype/module-example.html)。

模板根：

```html
<html lang="zh-CN" data-lore-template="2">
```

公共字段：

```html
<p data-lore-shared="地点"></p>
```

实体字段：

```html
<article data-lore-each="人物">
  <h3 data-lore-name></h3>
  <p data-lore-field="身体状况"></p>
</article>
```

HTML 只决定展示，不决定保存字段。完整合同见 [Template API v2](../HTML模板适配指南.md)。

## 5. 保存并开始

预览/应用外观后点击 **保存 HTML 并启用本聊天**。第一次有效状态回复建立 full，之后只提交发生变化的栏目。

一个栏目内部仍是完整当前值替换；新值要保留该栏目里仍成立的旧事实。

## 6. 0.12.3：结构性改栏目

换颜色/布局/显示顺序不是 schema 变化，可以继续使用现有状态。

增删、改名模块或栏目属于 DataSchema 变化。0.12.3 可在 **规则配置 → 聊天维护** 输入 `删除旧配置`，执行 **彻底删除旧配置**，随后重新绑定条目、制作/应用匹配新 schema 的 HTML、再启用聊天。

该操作会删除本脚本配置与当前聊天 LoreState 状态/快照/回档/更新绑定，但保留聊天正文、世界书和全局 API；不可撤销，重要数据先备份。

## 7. 升级

从 `0.11.0`～`0.12.2` 升级到 0.12.3，合法 v2 外观、v3 状态和快照无需因版本升级迁移。0.10.6 或更早旧 HTML 需要重制 v2 外观。

## 8. 可选功能

- 独立状态模型/多协议 API：[额外模型与 API 预设](../额外模型与API预设.md)。
- 按状态驱动动态世界书：[EJS / 动态世界书](../EJS动态世界书.md)，需用户自行安装 ST-Prompt-Template。

## 发布前检查

至少验证：固定脚本版本、世界书与条目绑定、一次 full → delta、跨模块更新、刷新/切聊天、回档、Template API v2 外观、过滤规则、导出后重新导入；使用额外模型/EJS 时再测真实服务与扩展组合。

自动化测试不等于真实 SillyTavern、实际模型、手机和长期游玩已经验收。
