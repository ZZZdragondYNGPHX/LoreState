# 0.12.1 · 条目绑定与首次 HTML 制作修复

基底：`main / 9c7a6428ca8862ba240d0dc76153783e23883fb8`，与 `0.12.0` 一致。

## 问题与修复

首次设置尚未保存 HTML 时，刷新世界书或切入外观制作会重建列表，丢失用户选择并默认选第一条；第一条不是模块规则时，HTML 制作无法继续。

- 设置第一步新增“确认绑定状态栏条目”。只保存准备使用的世界书与条目，不启用聊天、不改状态或活动规则。
- 刷新与切页保留选择；已确认绑定能从脚本配置恢复。原条目消失时留空并提示重新选择，避免误用第一条。
- 首次外观请求从所选条目读取栏目；保存 HTML 并启用仍经过原来的模板、栏目兼容和聊天保护。
- 异步读取丢弃过时结果；聊天切换清除临时选择。无新增依赖或宿主接口。

## 使用

选择世界书和条目 → 确认绑定状态栏条目 → 打开外观制作台 → 配置生成 API 并生成 HTML 草稿 → 保存 HTML 并启用本聊天。

已有存档、v3 状态、v2 模板和 EJS 只读桥接保持原协议。旧固定标签不移动。

## 验证与边界

构建、语法与版本守卫、132 项 Node 测试、136 项浏览器检查通过（29 项模板、94 项最终 bundle 模拟宿主、13 项 EJS）。最终 bundle 的浏览器回归覆盖非首条目、刷新、双向切页、独立绑定、配置序列化恢复、首次 HTML 生成与条目删除。

浏览器使用合成宿主和模型响应；未完成真实 SillyTavern、实际模型及手机实机验收，未设置人工验收状态。下一验收门为用户在真实酒馆导入 0.12.1 后完成上述操作。
