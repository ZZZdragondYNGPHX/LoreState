# LoreState 文档

当前稳定版是不可移动标签 **`0.12.1`**；固定入口不会随 `main` 变化，`main` 远程组件仅用于持续开发。固定安装使用 [0.12.1 远程组件](../prototype/dist/0.12.1/lorestate-script.json)。版本与 tag 规则见 [版本管理](版本管理.md)。

当前主线使用 **XML v3 状态协议 + 模块条目 + Template API v2**。`0.11.1` 起提供 API 辅助外观制作；`0.12.0` 起提供可选的 EJS / 动态世界书只读桥接；`0.12.1` 修复首次条目绑定和首次 HTML 制作流程。现有 v3 状态、快照和合法 v2 模板保持兼容。

## 推荐的首次流程

1. 使用 `0.12.1` 固定组件，只启用一份 LoreState。
2. 在世界书建立 `【LoreState模块 v1】` 条目。
3. 在设置中选择世界书和条目，点击 **确认绑定状态栏条目**。
4. 在外观制作台生成/修改 HTML，或粘贴现成的 Template API v2 模板。
5. 预览并保存 HTML，启用当前聊天。
6. 用独立测试聊天验证一次 `full → delta`、刷新恢复、切聊天和导出。
