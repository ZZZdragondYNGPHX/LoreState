## 第一次使用

1. 导入 [0.13.1 固定远程组件](../prototype/dist/0.13.1/lorestate-script.json)，只启用一份 LoreState。
2. 在角色 / 聊天世界书创建 `【LoreState模块 v1】` 条目，可参考 [模块示例](../prototype/module-example.txt)。
3. 在 **规则配置** 选择世界书和条目，点击 **确认绑定状态栏条目**。
4. 在 **外观制作** 生成 / 修改 HTML，或粘贴合法 Template API v2 模板。
5. 预览并应用外观，然后 **保存 HTML 并启用本聊天**。
6. 用独立测试聊天验证 `full → delta`、刷新恢复、切聊天、回档与导出。

## 重新制卡 / 换栏目（0.12.3 起）

如果要增删 / 改名字段，不要只改 HTML。0.12.3 起可以在 **规则配置 → 聊天维护** 输入 `删除旧配置` 并执行 **彻底删除旧配置**，随后重新绑定条目、制作 / 应用 HTML、再启用聊天。

该操作会删除本脚本配置和**当前聊天**的 LoreState 状态、快照、回档、更新绑定与恢复备份；保留聊天正文、世界书、全局 API 预设和其他命名空间。详情见 [0.12.3 发布说明](发布材料/0.12.3-配置重置与多协议API.md)。

## 0.13.1 核对路径修复

0.13.1 不改变 DataSchema 或 XML 协议；状态模型的字段更新判断只采用状态栏条目与自定义更新核对规则，程序动态列出当前 schema 的精确核对 path，避免作者栏目名被缩写或猜错。详见 [0.13.1 发布说明](发布材料/0.13.1-更新核对路径修复.md)。

## 0.13.0 更新核对与随卡导出

0.13.0 的状态请求会先输出可校验的 `LoreStateReview` 摘要，再提交 v3 状态更新。作者可保存自定义核对规则、作者默认初始档案和可移植更新默认值。

准备分享角色卡时，到 **规则配置 → 角色卡导出** 执行 **检查并准备角色卡导出**，再使用酒馆本身导出角色卡。这个步骤会同步规则副本、校验外观和作者默认档案、刷新过滤正则并确认当前脚本的导出开关。完整说明见 [更新核对与随卡导出](更新核对与随卡导出.md)。
