# 更新前核对与随卡导出 · 0.13.0

## 0.13.1：核对判断规则来源

从 0.13.1 起，**字段是否变化的判断规则只来自状态栏条目与“自定义更新核对规则”**。剧情正文和旧状态是事实资料；LoreState 内置提示只负责 XML/JSON 格式、冷热档读取权限、full/delta 以及当前 schema 的精确 path 清单，不再额外规定“时间、地点、关系、事件”等默认核对重点。

`LoreStateReview.path` 必须逐字使用作者真实栏目名。例如公共栏目声明为 `当前时间`、`当前地点` 时，只接受 `/shared/当前时间`、`/shared/当前地点`，不会用 `/shared/时间`、`/shared/地点` 之类缩写代替。

## 先核对，再更新

同一次请求先输出简短 `LoreStateReview` 摘要，再输出 v3 `LoreState` 更新块。无需为核对新增一次模型调用。

摘要逐项覆盖公共栏目和已完整加载实体的栏目，用 `path`、`change`、`reason` 记录判断。程序拒绝漏查栏目、计划更新却未产生变化、声明保留却发生变化，以及未读取冷档的字段核对。实体进出场、关联变化、事件标记和整体删除也需对应核对。

额外模型必须返回摘要；成功后只有状态块写回正文，原始摘要在“更新与恢复 → 最近一次 LoreState 更新诊断”查看。随正文模式的完整摘要会被显示/历史提示词正则隐藏，状态对象不保存摘要。旧消息没有摘要仍可回放；随正文模式兼容这类旧输出，缺摘要本身不会使旧记录失效。摘要存在时一律校验。

程序检查的是摘要与实际状态差异的一致性，不能证明模型对剧情的理解正确。若模型将漏掉的事实判断为“不变”，仍需实际对话对照检查。字段较多时摘要会增加输出 tokens；模型截断或校验失败不会部分写入状态。

## 自定义更新核对规则

进入 **模型连接 → 状态更新绑定 → 自定义更新核对规则**，填写后点击 **保存状态更新绑定**。

例如：

```text
好感度只在明确的信任、帮助或冲突事件后变化。
物品交付时同时核对持有人与背包；计划交付不算已经交付。
战斗结束核对伤势与消耗；没有出现的角色不推测后台变化。
```

最多 6000 字符，留空使用默认核对步骤。“恢复默认核对规则”先清空编辑框，保存后生效。该规则随角色卡脚本数据保存，同卡聊天共用；随正文、额外模型、失败重算及提示预览都会使用它。规则用于定义变化条件与核对重点，不替换状态格式、栏目覆盖和读取权限。

保存绑定同时保存可移植的更新默认值：更新方式、自动更新、流式、请求次数、超时。尚未配置的聊天使用这些默认值；已有聊天绑定优先。个人 API 绑定、连接来源、酒馆预设名称仍留在聊天/本地，导入者使用额外模型前必须配置自己的连接。

## 作者档案

**初始档案与字段约束 → 预览作者配置 → 保存为新聊天默认配置**，会把作者初值和字段约束保存到随卡脚本数据的 `authorPolicy`。新聊天可从同一初始状态开始。

“应用到尚未开始的本聊天”只改变当前聊天；已有游玩进度、冷热档、快照和回档不属于作者默认档案，也不会通过导出准备变成作者初值。

## 导出前准备

1. 保存外观、自定义核对规则和作者默认档案。
2. 在 **规则配置 → 角色卡导出** 点击 **检查并准备角色卡导出**。
3. 工具同步当前绑定条目的完整规则副本，校验当前 HTML 和作者默认档案，保存更新默认值，并开启当前角色脚本的数据/按钮导出开关、刷新状态过滤正则。
4. 使用酒馆本身导出角色卡，再在独立测试副本导入检查。

规则副本也会在首次绑定和保存启用时记录。导出准备会再次从世界书同步最新内容；如果之后编辑了世界书，请重新准备。原世界书可读取时仍使用实时条目；新环境找不到该世界书时使用随卡副本。已有世界书明确删除了绑定条目时会报错，不用旧副本掩盖删除。副本没有历史游玩状态。

| 内容 | 保存位置 / 导出行为 |
| --- | --- |
| 当前 HTML、命名预设、栏目结构 | 角色脚本数据，随卡 |
| 自定义更新核对规则 | 角色脚本数据，随卡 |
| 作者默认初始档案、字段约束 | 角色脚本数据，随卡 |
| 模块条目规则副本、原绑定位置 | 角色脚本数据，随卡 |
| 更新方式、自动/流式、重试/超时默认值 | 角色脚本数据，随卡 |
| LoreState 程序 | 角色脚本中的远程 loader；固定版固定到 0.13.0 |
| 过滤正则 | 角色局部正则；准备导出与正常生成前会刷新 |
| 密钥、API 地址、模型和个人酒馆预设 | 本地用户/聊天设置，不随卡携带 |
| 实际聊天状态、冷热档、快照、撤销记录 | 聊天数据，另行备份聊天 |
| 未保存外观草稿、诊断输出 | 编辑器/当前会话内存，不作为卡配置 |
| 其他剧情世界书、动态 EJS 条目 | 按酒馆角色世界书导出；规则副本只包含选中的 LoreState 条目 |
| Tavern Helper、可选 ST-Prompt-Template | 接收方安装/启用；不是角色卡内置扩展 |

接收方需要启用角色脚本与局部正则，并按界面完成聊天启用。远程 loader 仍需要网络。自动化 JSON 往返和模拟宿主测试不代表已经完成真实 PNG/JSON 角色卡的导出导入验收。
